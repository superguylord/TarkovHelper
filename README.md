# TarkovHelper

Личный помощник для Escape from Tarkov: карта с позицией, трекер квестов, цены предметов, оверлей поверх игры.

## Запуск

Ярлык **TarkovHelper** на рабочем столе запускает собранное приложение (`dist/win-unpacked/TarkovHelper.exe`).

После изменений в коде приложение нужно пересобрать: двойной клик по `Пересобрать приложение.bat` (или `npm run pack`).
Для разработки: `npm run dev` — режим с автообновлением.

## Как пользоваться

Игра должна быть в режиме **«Оконный без рамки»**, иначе оверлей не виден.

| Клавиша | Что делает |
| --- | --- |
| F8 | Оверлей поверх игры: карта, квесты, цены (Esc — закрыть) |
| F7 | Мини-карта в углу экрана (клики проходят в игру) |
| F9 | Цена предмета под курсором (наведите курсор на предмет в инвентаре) |
| PrtSc (в игре) | Скриншот — позиция и конус обзора появятся на карте |

Клавиши меняются в «Настройках».

На карте — точки ваших активных квестов (задания на убийство не отмечаются) и выходы для ЧВК или Дикого.
Клик по квесту в списке слева или по маркеру открывает карточку: цели с галочками, подсказки (ключи, что взять
с собой, FIR) и гайд «Как выполнить» из русской вики.

## Откуда данные

- **Карта, квесты, цены** — [tarkov.dev](https://tarkov.dev) (кэшируются локально, работают без интернета).
- **Текущая карта, режим PvP/PvE, взятые и выполненные квесты** — логи игры (`<папка игры>/Logs`).
- **Позиция** — имя файла скриншота (игра записывает туда координаты).
- **Гайды по квестам** — раздел «Выполнение» из [русской вики](https://escapefromtarkov.fandom.com/ru), кэш на неделю.
- **Цена под курсором** — снимок области экрана и распознавание текста (tesseract.js).

Приложение не читает память игры, не внедряется в процесс и ничего не нажимает за игрока.

## Где что лежит

- `src/main` — фоновая часть: окна, горячие клавиши, логи, скриншоты, OCR, загрузка данных.
- `src/renderer` — интерфейс (React).
- `src/shared/types.ts` — общие типы.
- Настройки и прогресс: `%APPDATA%/TarkovHelper`.
